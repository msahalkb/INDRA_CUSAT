# Data

Raw data is not committed. Download it from Figshare and place it here:

- Source: Zhao Q. et al., "Chinese diabetes datasets for data-driven machine learning", Scientific Data 10, 35 (2023).
- Figshare collection: https://doi.org/10.6084/m9.figshare.c.6310860
- Needed: `Shanghai_T2DM/` (time-series Excel files) -> `data/raw/Shanghai_T2DM/`
- Needed: `Shanghai_T2DM_Summary.xlsx` -> `data/raw/`
- License: check the Figshare page (the paper is CC BY 4.0) and cite it.

Heart rate and step count are NOT in this dataset. They are synthetic (see `src/`).
